Generate strong passwords and memorable passphrases. Check password strength and, if you choose, check breach exposure without sending your password.

● Password generation and strength checks run locally in this browser.

01 / GENERATOR

Random password

On-device

Generate a password to estimate its strength.

02 / PASSPHRASE

Memorable phrase

Random words

Words are selected using the browser's cryptographic random generator. Add a private separator or extra words if a service requires it.

03 / BREACH CHECK

Was a password exposed?

Optional online check

Uses the Have I Been Pwned Pwned Passwords k-anonymity range API. Only the first 5 characters of a SHA-1 hash are sent; your password and full hash are not sent. The lookup is optional.

Nothing is checked until you press the button.

Official links

These references are maintained as a curated directory. The breach database is queried live only when you request a check. This static app does not silently upload or background-scan passwords.
