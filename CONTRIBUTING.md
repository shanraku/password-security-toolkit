# Contributing

Thanks for helping improve Password Security Toolkit.

- Keep password generation cryptographically secure. Never replace Web Crypto with `Math.random()`.
- Never transmit plaintext passwords or full password hashes.
- Keep local-only features local; explain any network request clearly.
- Prefer official, maintained security references and include attribution.
- Do not add analytics, trackers or hidden data collection.
- Test changes in current desktop and mobile browsers before submitting a pull request.
- Use clear commits and describe the security and privacy impact of changes.

Never include real passwords, API keys, tokens or personal data in issues or pull requests.
